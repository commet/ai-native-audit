# Design — 채점 시각화 (hero visual 후보)

> 채점이 보여줘야 할 3가지: ① 7축 점수 ② "신뢰가 레버리지를 곱한다"는 게이트 로직 ③ 해자 판정(MOAT/EMERGING/COMMODITY/NOVICE). 단순 7축 막대/레이더로는 ②③을 못 담음 → hero visual 결정이 핵심 설계.
> 예시 점수: D1 72·D2 58·D3 80·D4 55·D5 55·D6 70·D7 78 → 종합 ≈69, EMERGING (G1의 D2<70 차단).
> ✅ **결정(2026-06-01)**: hero = **"남들이 따라할 수 있나?" 스펙트럼 띠**(무용어, 양 끝 라벨이 설명 대신) + "다음 한 끗" 처방. 그 아래 A(7축 그룹막대)·C(판정 근거 펼침)는 스크롤 보조. B는 "채점 원리" 온보딩 1회용. **렌더 = 브라우저 SVG(HTML-first)**, 터미널은 한 줄 글랜스만.
>
> **무용어 hero 스펙트럼 (채택):**
> ```
>  당신의 AI 활용 — 남들이 따라할 수 있나?
>  따라하기 쉬움                          따라잡기 어려움
>  (누구나 하는 수준)                       (당신만의 무기)
>  ├──────────●───────────────◆──────────────┤
>        입문   누구나      너 ▲ 발전 중        내 무기
>  ▸ 딱 한 끗: 검증 습관(D2)만 올리면 → '내 무기'
> ```
> ("MOAT/COMMODITY" 영어 등급은 작은 칩으로만, 설명은 양 끝 라벨이 전담.)
>
> ──────────── 이하 초기 4안 목업(터미널 스케치, 참고용) ────────────

## A. 속성별 그룹 막대 (직관·구현 쉬움)
```
 AI-NATIVE 69/100   EMERGING ◐   (MOAT까지 1관문)

 LEVERAGE 크기 ──────────────── avg 69
   D1 위임 고도      ███████░░░ 72
   D3 컨텍스트       ████████░░ 80
   D4 오케스트레이션 █████░░░░░ 55
   D6 반복·폐기      ███████░░░ 70
 TRUST 신뢰 ──────────────────── avg 56  ⚠
   D2 검증           ██████░░░░ 58  ← 차단축
   D5 한계 운전      █████░░░░░ 55
 COMPOUNDING 복리 ────────────── 78  ✓
   D7 자산 복리화    ████████░░ 78
```

## B. 공식 시각화 ×·↗ (왜 그 점수인지 = 게이트 교육, 온보딩용)
```
   레버리지        신뢰 게이트       복리
   (크기)      ×   (부호)      ↗    (지속)     =  판정
 ┌──────────┐    ┌─────────┐     ┌─────────┐
 │ D1·D3    │    │  D2 58  │     │  D7 78  │
 │ D4·D6    │ ×  │  D5 55  │  ↗  │   ✓     │  =  EMERGING ◐
 │  ≈69 高  │    │  ≈56 ⚠ │     │         │
 └──────────┘    └─────────┘     └─────────┘
                      ▲ 신뢰<70이 레버리지를 깎음 → 해자 미달
     "빠른데 가끔 틀림". 검증만 올리면 MOAT.
```

## C. 해자 3관문 체크 (판정 로직 + glass-box drill-down)
```
 해자(MOAT) 판정 — 3관문
 ┌────────────────────────────────────┐
 │ G1 분별력  D2≥70 ∧ D3≥70  ✗ (D2 58) │ ← 막힘
 │ G2 복리    D7≥65           ✓ (78)    │
 │ G3 비취약  최저축≥45       ✓ (55)    │
 └────────────────────────────────────┘
 결과: EMERGING ◐  (3관문 중 2 통과)
 다음 한 수: D2 58→70 → MOAT 승격
 [▸ D2를 깎은 인스턴스 3건 보기]
```

## D. 프로파일+처방 우선 (점수 보조, 타당도 논란 회피·포지셔닝 정합)
```
 프로파일: 첨탑형(설계자)  ◢◣
 강점 ▏컨텍스트·복리     약점 ▏검증·오케스트레이션

 ▶ 다음 한 수 (처방)
  1. 검증(D2): 분석노트 5건 중 4건 반증 시도 없음
     → 매 결론에 "반례는?" 1줄. 7일 후 재측정.  [근거: note A·B·C ▸]
  2. 오케(D4): 13개 작업 전부 직렬 수동
     → 1건 병렬 위임 시도.
 ────────────────────────────────────
 점수 69 · EMERGING (근거)   ← 보조
```

## 권고 레이아웃 (잠정)
세로 스택: **D(처방 띠, 맨 위) → A(7축 그룹 막대, hero) → C(해자 3관문+근거 펼치기)**. B는 "채점 원리 알아보기" 토글/온보딩 1회. 실제 렌더 = 순수 SVG(의존성 0, 오프라인).
